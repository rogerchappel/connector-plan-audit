# Contributing

Thanks for helping improve `connector-plan-audit`.

## Local Checks

Before opening a pull request, run:

```sh
npm install
npm run release:check
```

`release:check` runs the syntax checks, tests, Markdown and JSON smoke commands, and package smoke check.

## Pull Requests

Keep changes focused and include fixtures or tests for behavior changes. Avoid committing real connector payloads, credentials, account IDs, or private approval records.
