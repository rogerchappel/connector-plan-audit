# Security Policy

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by opening a GitHub security advisory or by contacting the repository maintainer directly.

Do not include secrets, credentials, or private connector payloads in public issues. If a report needs reproduction data, use redacted fixtures that preserve the approval and rollback shape without exposing real customer or account data.

## Supported Versions

The current `main` branch is supported for security fixes until the project publishes versioned release lines.
